# 把订单同步到 Google Sheet

顾客在自己手机上下的单,默认只会留在顾客自己的浏览器里,`/admin` 看不到。
按下面做一次,每张订单就会自动多出一份记录到你的 Google Sheet(免费)。
WhatsApp 仍然是真正的下单渠道,Sheet 只是一份备份与对账用的记录。

## 步骤

1. 用你的 Google 账号新建一个空白 Google Sheet,命名例如 `Bearkery Orders`。
2. 在 Sheet 里点 **扩展程序 → Apps Script**。
3. 删掉编辑器里原有的代码,把本目录的 `Code.gs` 全部内容贴进去,保存。
4. 在上方函数下拉选 `setup`,点 **运行**(第一次会要求授权,选你自己的账号)。完成后 Sheet 里会出现 `Orders` 分页和表头。
5. 点右上角 **部署 → 新建部署 → 类型选「网页应用」**:
   - 执行身份:**我**
   - 谁可以访问:**任何人**
6. 部署后复制 **网页应用网址**(以 `/exec` 结尾)。在浏览器打开它,看到 `Bearkery order sheet is live.` 就对了。
7. 在网站项目根目录新建 `.env.local`(参考 `.env.example`),写入:

   ```
   NEXT_PUBLIC_ORDER_WEBHOOK=你复制的网址
   ```

8. 重新启动或重新部署网站(这个变量在构建时写入,改了要重新构建才生效)。

## 之后怎么确认

- 在结账页网址后面加 `?demo=1`,会出现「Record a demo order」测试按钮。点一下,Sheet 里应出现一行 `is_demo = TRUE` 的记录。测试完可以直接删掉那一行。
- 如果你改了 `Code.gs`,要在 Apps Script 里 **部署 → 管理部署 → 编辑 → 新版本**,网址才会用新代码。

## 要知道的限制

- 这个网址是公开的(网页应用需要「任何人」才能让顾客的手机写入),所以理论上任何知道网址的人都能往里提交订单。脚本已经做了这些防护:校验订单编号格式、限制商品数量与文字长度、同一订单编号不会重复写入、以 `=` `+` `-` `@` 开头的内容会被当成纯文本(避免被当公式执行)。**不要把这个网址贴到公开的地方。**
- 网站是在顾客点「透过 WhatsApp 送出订单」的那一刻写入 Sheet 的,不管顾客最后有没有按下 WhatsApp 的发送键。所以 Sheet 里的单要以 WhatsApp 实际收到的为准,`status` 列可以手动改成 confirmed / cancelled 等。
- 订单资料含顾客的姓名、电话与地址,请不要把这个 Sheet 公开分享。
- 之后改用自己的数据库时,把 `NEXT_PUBLIC_ORDER_WEBHOOK` 指向你自己的接口即可,网站其余代码不用改。
